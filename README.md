# mpm

## Multiple Project Manager

- Script to manage many git projects.
- Setup is rather ad-hoc combination of custom scripts and configs.
- Directory setup:
  - `~/projects/dev/` - top level dev dir
    - `mpm` - Wrapper script with various group setups and custom link to main
      `mpm` script.
    - `mpm-GROUP` - Per-group wrapper.
    - `mpm-GROUP.conf` - Per-group config.
- See [examples](./examples) for configuration examples.
